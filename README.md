# Rosenfu

日本の実際の地図上に鉄道路線を建設し、ダイヤと旅客の流れを楽しむ架空鉄道ゲームの開発プロジェクトです。

路線建設・ダイヤ設定・旅客需要・旅客流動を中心に、少人数で同じワールドを共有するマルチプレイを目指します。複雑な経営管理よりも、路線や運行を変えたときの鉄道網の変化を重視します。

## 開発状況

- **α0.1（`main`）**: 建設・編集・保存の基盤を統合済みです。自作のオフラインサンプル背景またはオンライン実地図で、駅・線路・路線・運行系統を編集し、別々のワールドとして保存・再開できます。ここでいう運行系統の編集は、列車の走行や旅客シミュレーションではありません。
- **α0.2（`dev/alpha-0.2-integration`）**: ゲーム内時刻、簡易ダイヤと列車運行、固定の起終点・需要による旅客経路の試作、セーブデータの名前変更を開発側に統合しています。バスと道路上のトラムは試験データでの検証が中心で、実道路での利用や全国の網羅性は未確認です。α0.2はまだ`main`に統合していません。

α0.1のソース統合や、α0.2のWindows用インストーラーのCI検証は、一般向けの配布開始を意味しません。公開済みの配布物は[Releases](https://github.com/Mei8n/rosenfu/releases)で案内します。公開日や最終動作要件は未定です。

起動方法と検証範囲は[開発環境と起動手順](docs/development.md)を参照してください。

## 技術構成

現行試作は Tauri 2、React / TypeScript、Rust、JSON保存で構成しています。MapLibre GL JS、SQLite、マルチ通信方式は検討対象であり、採用済みではありません。地理・統計データの取得・配布方法も検証して決定します。
