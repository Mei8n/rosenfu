# オフライン実地図・交通参照データの調査

調査日: 2026-11-12

位置付け: 公開資料に基づく方式比較と設計提案。採用決定、配布許諾の取得、実装完了報告ではない。
ユーザー要件は、OSM の実地図を使い、必要なデータを事前取得した後はシングルプレイ中にネット接続を不要とすること。
既存の [実地図背景](map-backgrounds.md) と [建設・サービス方針](construction-and-service-planning.md) を上書きしない。

## 1. 最重要の区別

OSM データを取得・加工することと、OSM 財団の標準画像タイル配信を大量取得することは別である。
公式標準タイルの一括ダウンロードやオフライン用地域保存は利用方針で禁止されている。
通常の表示キャッシュを増やすだけでは、適法なオフライン地図製品にはならない。
配布を想定した PBF データ、地域抽出可能な地図アーカイブ、自前生成、または明示的なオフライン契約を使う。
[OSM 標準タイル利用方針](https://operations.osmfoundation.org/policies/tiles/)

## 3. 地域パック案（未決定）

短期試作は Protomaps 地域抽出と PBF 由来の交通参照データを別々に用意する。
長期候補は、同一の OSM PBF から背景と交通参照データを生成する方式である。
MapLibre、PMTiles、SQLite 等の正式採用をこのメモでは決めない。

想定構成:
- 背景アーカイブ: 地域のベクタータイル。
- 交通参照データ: 実在駅・線路・道路、元 OSM ID、タグ、形状、接続関係、空間検索索引。
- 表示資産: スタイル、アイコン、スプライト、日本語フォント等。
- manifest: 地域範囲、データ日時、ビルド日時、形式版、生成器版、ファイル容量・ハッシュ、出典・ライセンス。
- 同梱する利用条件・帰属案内。各表示資産の再配布条件も別途確認する。

[Osmium](https://osmcode.org/osmium-tool/manual.html) は地域抽出・タグ選別・参照整合確認の候補。
[Protomaps 自前生成](https://docs.protomaps.com/basemaps/build) は Planetiler を使い、OSM 抽出から背景を生成する公開工程を提供する。
生成には海陸ポリゴン等の追加素材も使われるため、それぞれの出典・条件をパックに反映する。
[PMTiles CLI](https://docs.protomaps.com/pmtiles/cli) はローカルアーカイブの扱いと地域抽出を提供する。

### 表示と交通グラフを分離する

描画用ベクターは簡略化・タイル境界分割・タグ省略があり得る。
それをそのままスナップ・経路探索の原本にするのではなく、元 PBF から必要な詳細を保持した交通参照データを作る。

- 実在駅は参考レイヤーであり、表示しただけでゲーム内駅を建設しない。
- 駅、停留所、ホーム、出入口、駅を表す関係の分類・重複統合を検討する。
- 地理的交差だけで線路を接続しない。橋・トンネル・階層・共通ノード等を検査する。
- 境界をまたぐ線路・関係・参照先を欠落させない抽出方式を検証する。
- OSM の位置・営業状態・接続の完全性は保証しない。不足を現実の不存在と解釈しない。

これらは設計上の提案であり、抽出器・接続判定・スナップ機能の実装済み事項ではない。

## 4. データ版とプレイヤー設備の分離

OSM 参照データと、ユーザーがゲーム内に建設した駅・物理線路・路線・系統を別のデータとして管理する。

- 参照データ側には元 ID とデータセット版を保持する。
- ゲーム設備は独立 ID・座標・形状を持つ。背景更新で削除・移動・再接続しない。
- セーブは参照した地域パックの識別子・版を記録する案を検討する。
- 新しい地図パックへの切替を、既存セーブの自動移行と同一視しない。
- スナップで参照データを利用した場合の由来を追跡できる設計を検討する。
- OSM 由来の加工データと独立したユーザー創作の法的扱いは、実際の保存・配布構造に即して確認する。分離しただけで全ての義務が消えるとは扱わない。

更新は任意取得・整合性確認後に切り替える案がよい。ゲーム起動時のオンライン更新を必須にしない。
旧版パックの保管、容量上限、欠落時の挙動、移行方式は未決定。

## 5. 容量・配布の見積りに使える公開値

2026-11-12 に確認した Geofabrik 表示値:
- 日本全体 PBF: 約 2.4 GB
- 関東: 約 500 MB
- 近畿: 約 339 MB
- 北海道: 約 181 MB

これらは圧縮元データの値であり、完成パック容量や RAM 必要量ではない。
[出典: Geofabrik](https://download.geofabrik.de/asia/japan.html)

Protomaps の世界背景はズーム 0–15 で約 120 GB。地域抽出と最大ズーム指定が可能。
全世界取得を前提にせず、小地域で背景・交通データ・フォントを含む実容量を計測する。
[出典: Protomaps](https://docs.protomaps.com/basemaps/downloads)

配布サーバー/CDN、更新頻度、帯域費用、パック分割単位、再配布条件は未確定。
Protomaps の配布 URL をゲーム実行時に直接参照し続ける方式は推奨されていない。
取得元、ビルド版、ハッシュを記録し、自ら管理する配布物の整合性を検証する案とする。

## 6. 帰属・ライセンス上の整理

OSM データは ODbL。オフラインでも出典とライセンス案内を残す。
画面の帰属表示に加え、ネットなしで読める説明・ライセンス文書を同梱する案とする。
表示資産、生成ツール、追加データは OSM と別の条件を持ち得る。

加工データベースと地図画像等の Produced Work は扱いが異なる。
交通 DB や抽出データの配布方法、加工内容の提供義務を、配布前に実際の構成に即して整理する。
ゲームコード全体が自動的に ODbL になるとは断定しない。
一方、画面で出典を示すだけで全ての配布義務を満たすとも断定しない。

- [OSM 著作権・ライセンス](https://www.openstreetmap.org/copyright)
- [OSMF 帰属指針](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines)
- [OSMF Produced Work 指針](https://osmfoundation.org/wiki/Licence/Community_Guidelines/Produced_Work_-_Guideline)

商用データ購入やダウンロード可能という事実だけでは、ゲームへの同梱・第三者再配布・無期限利用の承認にはならない。
契約・法的条件の最終確認は未完了。購入、契約、問い合わせ、再配布は本調査では行っていない。

## 7. オフラインの検証基準案

ネットワークを遮断した状態で次を確認する:
1. 起動、セーブ読込、地図移動、拡大縮小。
2. 日本語地名・駅名・アイコン表示。
3. 実在駅の検索・参照、線路/道路へのスナップ（各機能実装後）。
4. 建設・シミュレーション・保存・再開。
5. 地域外・欠損・破損パックの明示と、ゲーム設備を破壊しない動作。
6. 外部フォント、スタイル、検索API、認証、ライセンス確認、更新サービス等に必須依存が残っていないこと。

ブラウザの既存キャッシュが偶然残った状態だけで「完全オフライン」と認定しない。
本調査では地図データの実ダウンロード・生成・容量計測・ネット遮断テストは行っていない。
