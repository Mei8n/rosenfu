# 開発ロードマップ

更新日: 2026-11-12

開発者2人と別途テスト担当を前提とした段階案です。追加参加者を見込んだ日程短縮は織り込みません。
作業時間と技術検証が未確定のため、期日は設定しません。版番号は目標を表し、リリース済みではありません。
段階構成と初回正式版の範囲は本計画での提案です。要件の採用方針と区別し、変更理由をPRに残します。

## 段階と完了条件

| 段階 | 主な範囲 | 次へ進むための確認 |
| --- | --- | --- |
| 0.1 アルファ | 起動・技術検証、地図、駅・線路・路線・会社・系統の基本構造、保存・再開 | 小地域で建設・編集し、再起動後も同じ構造を復元できる。3 OSで起動確認し、データ利用条件の調査結果を記録する |
| 0.2 アルファ | 共通時刻、簡易ダイヤ、種別・停車駅、基礎OD需要と経路選択 | 新線・増発・停車駅変更で経路と利用者が変化する。鉄道未利用需要を区別できる |
| 0.3 アルファ | 需要4分類、曜日・時間帯、競争と乗換、簡易経営、サンドボックス、基本分析 | シングルで建設→運行→流動確認→改善を一巡できる。複数会社の収支と流動を確認できる |
| 0.4 アルファ | ゲーム内ホスト、所有権、同期、途中参加・再接続 | 2人から5人へ試験を拡大し、他社の不正編集や再接続時の二重処理を防ぐ。共通時計と保存が整合する |
| 0.5 アルファ | 専用サーバー、無人進行、資金保護、パターンダイヤ、互換性基盤 | 同じワールドを各実行形態で再開できる。移行・復旧と手動ダイヤ保護を検証し、ベータ条件を満たす |
| 0.6 ベータ | 継続プレイ、操作性・性能・安定性とモデル調整 | 過去ベータのワールドを移行でき、公開した動作規模で重大な不具合が解消している |
| 1.0 RC | 正式版候補の検証、配布確認 | 既知のリリース阻害不具合がなく、復旧手順と各OSの配布物を確認済み |
| 1.0 正式版 | 初回範囲の公開 | リリースノート、既知の制約、互換性情報を公開する |

0.1では小地域で検証しますが、製品の対象は日本全国です。全国を詳細に同時計算できるという保証は別途性能測定で判断します。
ベータは期限が来たら移行する段階ではありません。条件未達ならアルファを継続します。

## ベータ開始条件

- [ ] 初回正式版の対象機能と未対応事項が確定し、上記0.1〜0.5の主要機能が動作する。
- [ ] 全国の任意地域で建設可能で、都市部・地方・地域間路線を検証済み。対応規模と動作要件を記載する。
- [ ] Windows / macOS / Linuxで起動、建設、運行、保存・再開を確認する。
- [ ] シングル、ゲーム内ホスト、専用サーバーで同じワールドを利用できる。
- [ ] [互換方針](world-compatibility.md)の移行・バックアップ・復旧試験を通過する。
- [ ] 所有権、参照ID、日付、運行データ、人口・需要・流動・資金の境界を固める。
- [ ] 将来の人口変動・子会社・バス・詳細ダイヤを追加する模擬移行で、既存ワールドの意味を維持できることを確認する。
- [ ] データの配布・キャッシュ・帰属表示の条件と、ネット接続が必要な範囲を確定する。
- [ ] 保存破損、進行不能、所有権違反などの重大な既知不具合がない。テスト担当が再現手順付きで確認する。

## 1.0以降へ送る候補

沿線人口変動、子会社、詳細ダイヤグラム、バス連携は1.0以降とする案です。
未採用と決定したわけではなく、人口変動等を初回必須とする場合はベータ前の段階に追加します。
ベータ前に必要なのは、これらを追加しても既存の会社・設備・運行・人口を破壊しない構造と移行手段の検証です。

## 2人での進め方

画面・地図・建設と、エンジン・保存・計算を分担する案を基本に、データ境界は共同でレビューします。
担当を固定せず、Issueごとに主担当を1人置きます。テスト担当には各アルファの小さな配布物と確認手順を渡します。
各段階の終了時に未完了項目、性能、次の範囲を確認し、必要なら以降の計画を更新します。
