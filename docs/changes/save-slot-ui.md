# 複数セーブUI（開発候補）

セーブ画面で保存済みワールドを選択し、新しいワールドを開始するか、編集中のワールドを別セーブとして保存する。初期会社設定からも一覧を開ける。上部「読込」は現在の保存先を再読込する従来の操作。

- 新規ワールドは未保存状態。初回保存で新スロットを作り、既存スロットを上書きしない。
- 別保存は常に別スロット。名前入力だけで既存保存を置換しない。
- ワールド・計画・未適用フォーム・視点の変更がある場合、新規開始/別スロット読込前に確認する。
- 読込/作成失敗は現在のワールドと入力を保持。保存失敗も名前を保持する。
- 非対応・破損スロットは理由を表示し、読込操作を無効にする。削除UIは作らない。
- 自動保存は確認済みの現在スロットに限定。初回保存前は無効。切替後に保存先を再確認する。
- API契約はlist_save_slots/create_new_world/save_world_as/load_save_slot。storage/sessionとの一体検証と最終CIが必要。ネイティブGUI受入は未確認。
