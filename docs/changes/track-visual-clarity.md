# 線路表示と不要情報の整理

- TrainsWorldの本人参考画像（2026-11-13）と公開ソース `circularsquare/trainsworld` の `app/src/map/network.ts` / `rendererShaders.ts`（参照checkout `6b8ef917`）を調査。背景との輪郭分離、計画と配置中の描き分け、一定以上の視認幅という考え方を参考に独立実装。コードの流用はしていない。
- 既設・分岐・内部接続・計画・道路/実在線/平行プレビューを共通の白い輪郭付き描画へ。既設線は濃い中立色、計画は青破線、配置中は青実線、拒否は赤破線、選択は黄土色。地下の破線・高架の背景帯・勾配端点表示は保持する。
- ズーム時も線幅を画面上で保持し、線幅設定に追従する。TrainsWorldのWebGL LOD/線数別ズーム遷移そのものは移植していない。
- Esc後に出現した内部線形一覧を除去。地図からの線路選択・編集・撤去と明示選択時の出典確認は維持。
- 踏切の地図位置マーカーを除去。道路交差判定、保存、集計、本人指定の箇所数と1箇所1億円の参考追加額（課金未実装）は変更しない。
- 保存形式、物理線形、接続、Undo/Redo、ヒット領域は変更しない。

## 検証上の注意

関連自動テストと型検査・frontend buildを実施。クラウドChromiumは実行環境のsocket制約で起動できず、実ブラウザの描画・Windows実機・密集地図での性能は未確認。DOM追加は各表示線につき背景stroke一本（イベントなし）。
