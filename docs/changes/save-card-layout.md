# セーブ一覧・計画駅入力のレイアウト

- セーブ操作を同じ折返し可能な列にまとめ、縦横に8pxの間隔を設ける。
- ワールド一覧はカード表示。現在のワールドは色と文字で区別し、APIが返す保存日時のみ表示する。
- 中央の選択ダイアログは最大600px。既存のセーブタブと読込・未保存確認の導線は維持する。
- APIにないサムネイル、プレイ時間、乗客、収支、サイズは表示しない。ファイル取込・削除・履歴も追加しない。
- 計画内訳の駅名入力と削除ボタンは同じgrid行に置き、入力列だけ縮む。無効な駅の理由は次行に分ける。

検証: 関連UI 18テスト、型チェック成功。CSS/DOMで折返し・間隔・縮小列・操作保持を検証。クラウドChromiumはsocket制約で起動できず、実ピクセルの視覚検証と本人PCでの確認は未実施。
