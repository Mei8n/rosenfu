# GSI水域取得の検証と残るcoverage制約

対象: `src/automaticWaterData.ts`。道路・session・共通coverage・高さprofile・物理判定はこの変更の対象外。

## 提供元と利用条件

- [国土地理院最適化ベクトルタイル](https://github.com/gsi-cyberjapan/optimal_bvmap) のPMTiles版を使用する。
- 固定配信先: `https://cyberjapandata.gsi.go.jp/xyz/optimal_bvmap-v1/optimal_bvmap-v1.pmtiles`
- 提供元READMEはPMTilesのZL4–16、2026年7月1日時点のデータを案内している。試験提供であり、URL・データ構成・属性等が変更される可能性がある。取得はZL14に限定する。
- [データ項目一覧](https://maps.gsi.go.jp/help/pdf/vector/optbv_dataspec.pdf) は `WA` を水域面（地物種別51・52）、`AdmArea` を行政区画として定義する。行政区画の存在だけでは、水域の欠落と陸地を区別できない。
- READMEは国土地理院コンテンツ利用規約の適用と出典明示を案内する。[同規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html) はPDL1.0を参照し、出典、加工した旨、第三者権利等の扱いを定める。コードのライセンスで地理データの利用条件を代替しない。
- 加工結果の表示例: 「国土地理院最適化ベクトルタイルをもとにRosenfuが加工」。提供元URLと利用条件へのリンクを併記する。既存Appの表示変更は別担当への引継ぎ事項。
- この調査を全国一括取得やオフラインパックの配布承認とみなさない。この変更は小地域の限定Range取得のみで、取得データの同梱・配布を追加しない。

## WA欠落は未解決であり、陸地と断定しない

2026-11-15のクラウド実取得で、次のZL14タイルを確認した（展開後サイズ）。

|地点|x/y|bytes|WA地物数|
|---|---|---:|---:|
|新宿付近|14549/6451|96,537|17|
|東京湾|14556/6461|260|9|
|甲府付近|14498/6452|71,643|30|
|富士山付近|14505/6469|158,973|レイヤー自体がない|

富士山付近はAdmArea 6、AdmBdry 32、Anno 20、Cntr 6,659、RdCL 21、TpgphArea 3、TpgphLine 11を含む。通信成功や他の地物の存在を、WAの完全性保証に置き換えない。公開仕様では「WAが省略された場合は水域不存在を保証する」という明示的契約を確認できていない。**このタイルは引き続きcoverage不明となり、現状の自動取得だけでは建設可能にできない。** この制約を解決済みとは報告しない。提供元の完全性契約、または出典・版・有効範囲が検証された別の水域データが必要。

一方、MVTに有効なWAレイヤーが明示されていて地物数が0なら、取得済みの空水域として扱う。`@mapbox/vector-tile` の `VectorTile` は地物数0のレイヤーを落とすため、`VectorTileLayer`でレイヤーを読み、明示的な空WAとレイヤー欠落を区別する。空WAは合成fixtureで検証しており、上記実タイルに含まれていたとの主張ではない。空body、WAなし、破損、未提供タイル、通信失敗は空水域に変換しない。

## 復旧・負荷・キャンセル

- 206、Content-Rangeの開始/終了/全体サイズ、実body長を検証。1応答と展開後は5MiBまで。無効応答はbodyをキャンセルし、全アーカイブを読み続けない。Rangeの整数オーバーフローも拒否する。
- 1回16タイル、直列取得、開始間隔250ms、pending上限32、成功タイル128件・24時間、失敗後60秒待機。待機中の呼び出しで待機時間を延長しない。
- PMTiles内部は成功したheader/directoryのみを保存する `ResolvedValueCache`。一度失敗したheader Promiseが残って再試行を永久に妨げる問題を回避する。
- 既知ETagと異なる206、ETag消失、または既知ETagに対する416では、アーカイブとdecoded tile cacheを破棄する。そのloadは失敗し、60秒後の再試行で新headerを取得する。古い版を収集中だったloadも、新世代を混ぜて公開しない。
- `load(bounds, signal?)` は購読を即時キャンセルできる。既に共有キューに入った1タイルは他の購読者のために完了・キャッシュ可能だが、キャンセル済みloadから次のタイルを追加しない。通信自身には25秒timeoutがある。
- **呼び出し側はこの変更では編集していない。** world/plan変更での実際のAbortSignal接続はApp/hook担当への引継ぎ事項。既存の世代チェックはそのまま残る。
- 複数タイルの合計も10,000面・100,000座標までに制限する。

## 検証

ネットワーク不要のMVT/PMTiles合成fixtureで、初回header失敗からの再取得、ETag/416更新、待機時間、Range/body制限、WA欠落と明示空、穴、破損、同時購読、キャンセル、TTLを検証する。プロバイダ実タイルをテスト資産として再配布しない。地上敷設禁止、30km境界、6m段差、Hermite profile等の物理ルールは統合側のテスト責務であり、この取得テストの成功で代替しない。
