# 道路参照と自動踏切（限定提供）

## 現在の提供範囲

有効な配信は東京中心部の固定36セルのみ。全国版の生成器と読込契約はあるが、
全国releaseは無効。取得範囲外・欠損セル・通信失敗は「道路なし」ではない。
`coverage_verified` は参照元からの抽出範囲を確認できたかを表すもので、
現実のすべての道路がOSMに登録されている保証ではない。未検証の範囲でも取得済みの
道路形状は交差判定に利用できるが、区域全体の確認済み判定には利用しない。
水域の確認・建設判定とは別機能であり、道路取得成功を水域確認に読み替えない。

## 着工時

- 「道路に合わせる」がOFFでも、計画線形の範囲に対する道路取得を行う。
- 取得完了前に着工した場合、既存の同じ取得要求を共有して最大25秒待つ。
  待機中は既存noticeに表示し、着工取消で下書きを保持できる。
- 取得成功時は道路snapshotと建設を同じトランザクションに含める。
- 範囲外・失敗・期限切れでも通常建設は可能。完了noticeに「踏切未確認」を残す。
  待機中にワールドや計画が変わった場合は古い計画を建てず中止する。
- 既存の包含snapshotは再利用し、出典の版・道路形状が矛盾する新規snapshotは
  既存情報を上書きしない。保存容量を圧迫する追加も見送って理由を表示する。

## 再判定と未対応の補完

踏切は保存された道路snapshotと現行の線路形状・実高さ・明示接続から派生する。
編集、撤去、接続変更、Undo/Redo、セーブ再読込の際は再算出するため、古い線路IDを
参照する独立した踏切レコードは残らない。取得中・再判定中には前のワールドの
結果を表示せず、遅れて返った古い結果も採用しない。

**取得失敗後に道路を再取得しただけでは、既設線路へsnapshotを自動追加しない。**
後の別の着工で該当範囲のsnapshotが保存されれば、その範囲内の既設線路も
再判定される。既に保存済みのsnapshotはオフライン再読込でも再判定できる。
既設線路専用の取得・永続化操作や、遅延取得成功に伴う自動ワールド編集は未対応。

橋・トンネル・非ゼロ階層・未知の道路高さから地上踏切を推定しない。
線路のカテゴリ名だけでなく区間の実高さを評価し、単なる端点接触や非接続の
同座標線路を通過交差として扱わない。
