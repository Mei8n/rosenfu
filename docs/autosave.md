# 手動保存とオートセーブ

手動保存は適用済みのワールドを保存します。未着工の線路計画は保存対象外ですが、保存によって画面から消えません。駅・会社・路線・系統の未適用編集は、適用または破棄するまで手動保存できません。

オートセーブは既定で5分間隔です。セーブデータタブで無効・1分・5分・10分に切替でき、設定は端末内に記録されます。適用済みワールドに手動未保存の変更がある場合のみ、操作・保存中を避けて専用 `world.autosave.rosenfu.json` へ保存します。未着工計画・未適用編集は対象外です。自動保存後も「手動未保存」の状態と終了確認は維持します。

自動保存は最新1件のスロットです。起動時や手動読込後に既存の自動保存が見つかった場合は書き込みを保留し、復元するか「以前の自動保存を置き換える」を明示選択する必要があります。データ確認中・確認失敗中も書き込みません。復元成功後はそのワールドの自動保存を継続します。手動保存ファイルは自動保存で上書きしません。既存保存方式と同じバックアップ・原子的置換を使用します。自動保存の失敗はセーブデータタブに表示され、次の間隔で再試行します。

「自動保存から復元」は、未保存変更・下書きがある場合に破棄確認を表示し、失敗時は現在の内容を保持します。成功時は自動保存の適用済みワールドだけを復元し、手動未保存の状態になります。その後の明示的な「保存」は通常の手動保存先を上書きします。

ブラウザプレビューでは自動保存しません。Windows/WebView実機でのファイル操作・タイマーは別途検証が必要です。強制終了直前の変更や未着工計画を保護する仕組みではありません。
