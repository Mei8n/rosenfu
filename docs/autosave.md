# 手動保存とオートセーブ

手動保存は建設済みワールドと未着工計画（計画駅を含む）を同時に保存します。駅・会社・路線・系統の未適用編集は、適用または破棄するまで手動保存できません。

オートセーブは実時間の2分間隔に固定です。ゲーム内時間の速度には連動せず、間隔の変更・無効化はできません。旧バージョンの端末内設定（無効・1分・5分・10分）は使用しません。ワールドまたは計画に手動未保存の変更がある場合のみ、操作・保存中を避けて専用 `world.autosave.rosenfu.json` へ保存します。未適用編集・未確定の参照候補は対象外です。自動保存後も「手動未保存」の状態と終了確認は維持します。

自動保存は各ワールドのスロットごとに最新1件を保持します。新規会社・ワールドは独立スロットを作成し、対象スロットの状態・版を確認して自動保存を開始します。既存データがあるだけで毎回置換許可を求めません。確認中・確認失敗中は書き込まず、外部変更や保存失敗時は停止して再確認を求めます。手動保存ファイルは自動保存で上書きせず、既存保存方式のバックアップ・原子的置換を使用します。スロット切替後に古い非同期応答で別ワールドへ書き込まないよう保護します。

「自動保存から復元」は、未保存変更・下書きがある場合に破棄確認を表示し、失敗時は現在の内容を保持します。成功時は保存時点のワールド・未着工計画・視点を復元し、手動未保存の状態になります。その後の明示的な「保存」は通常の手動保存先を上書きします。

ブラウザプレビューでは自動保存しません。Windows/WebView実機でのファイル操作・タイマーは別途検証が必要です。未着工計画も最後の自動保存時点まで保護しますが、強制終了直前など、その後の変更は保証しません。

## 地図の閲覧位置

手動保存・2分間隔の自動保存は、その時点の中心緯度・経度とズームも `view_state` に記録する。読込・再起動時は同じ保存世代の視点を復元する。閲覧位置だけの変更も自動保存対象だが、世界の編集ではないため終了時の未保存警告は増やさない。保存前に終了した閲覧位置は最後の保存位置へ戻る。

旧保存に視点がなければ既定の東京の視点へ戻し、直前に開いていた別ワールドの視点を引き継がない。読込失敗では現在の視点を変えない。背景・文字サイズなど端末表示設定は引き続きワールド保存と別である。

現在の `view_state` は単独プレイ用のローカルUIメタデータで、線路や需要などシミュレーションの物理状態ではない。保存ファイルを他人へ渡すと閲覧位置も含まれる。現在は各ワールドの保存スロットに分離し、将来のマルチプレイではこの値を共有ワールド同期対象にせず、ワールドIDと本人をキーとする端末側の個別視点として保存する。ホストの視点で他プレイヤーを移動させない。共有・エクスポート機能では個人視点の除外を既定とする。

## 複数ワールドと削除

新規会社・ワールドは独立した保存スロットを作成します。作成失敗時に旧ワールドの保存先へ書き込まないよう、保存先を切り離します。削除は確認後に復元可能な退避先へ移動し、削除済み一覧から復元できます。現在のスロットを削除しても編集中のワールドは画面に残り、次回保存は別のスロットになります。旧固定形式の削除は手動保存のみを対象とし、自動保存とバックアップは残します。詳細は[保存仕様](storage.md)を参照してください。

自動試験とネイティブGUI・実ファイルの操作確認は別判定です。セーブデータの名前変更はα0.2の開発統合に入りましたが、α0.1にはありません。別名保存・削除・復元とは別機能です。
