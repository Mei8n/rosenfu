# α0.2 駅・路線・系統の情報整理

## 参照
TrainsWorld `6b8ef91729e1e5812f3dcbaedd6c0a49fed6a84b` の
`trainworld/app/src/ui/StationsTab.tsx` と `LinesTab.tsx` を読み比較。
コードは流用せず、名称を主役とする一覧、選択後の詳細、運行情報との分離を参考にした。

## Rosenfuへの適用
- 駅: 駅グループを一行とし、名称、所属路線、実在するホーム数に限定。所属路線をチップに分けて読みやすくする。
- 路線: 名前と測定可能な距離を一覧に表示。検索を追加し、名称変更は小さい編集ボタンから実行する。詳細は所属駅の順序とし、内部の建設線形名・ID・重複した経路情報は表示しない。
- 系統: 名前と設定済み色/形/記号を主体にする。検索・選択状態・再クリックで選択解除を揃える。
- 乗客・収支・車両数は本人指定どおり系統側に残す。ただしシミュレーション未実装なので数値を捏造せず、ダッシュと一覧共通の説明一つにする。
- 路線は物理的経路、系統は運行設定というRosenfuの区別を維持。TrainsWorldの名称をそのまま移植しない。
- 入力破棄の確認、編集中の切替制約、保存失敗時の入力保持は既存の親コンポーネントに残す。

## 範囲外
地図での起終点編集とその操作案内は別作業。運行数値の計算や保存形式は変更しない。
実機表示・狭いウィンドウでの手動確認は別途必要。
