# 線路種別の基礎実装

通常 (`normal`)・高速 (`high_speed`)・トラム (`tram`) を線形ごとに保持する。
路線名や列車種別とは別で、手描き・参考形状コピーとも建設時に指定する。
建設済み線路には種別を表示する。既存線路の種別変更は未実装。

## 計画と保存

独立した各計画は種別と道路追従の希望値を保持する。計画切替、点のUndo/Redo、
着工失敗でも値は失われない。計画自体は従来どおり再起動後の保存対象外。
着工した線形の種別は手動保存とオートセーブに含まれる。
保存形式はschema 7。旧schema 1〜6を読み込む場合は通常線へ移行する。
新形式のファイルは旧アプリでは開けない。元ファイルのバックアップは既存保存機構を利用する。
中止した「計画永続化」のschema 7設計とは別の変更であり、計画の永続化は含まない。

## 道路追従と未実装の規格

トラムを選ぶと「道路に合わせる」は初期ON。検証済みローカル参照バンドルがある場合、候補を緑色表示し、同一OSM wayの起終点を明示して道路形状をコピーできる。
高速道路・ランプ・通行制限・橋・トンネル・非地上などを候補検索前に除外し、途中区間も再検証する。複数wayの自動探索や通行権の判定は未実装。
バンドル未読込・対象外道路ではONのまま自由な地図描画へフォールバックしない。明示的にOFFにすると自由敷設可能。
道路形状に沿っていても併用軌道とは判定しない。併用/専用の区間属性は今後実装する。

種類別の速度、曲線半径、勾配、費用、車両適合性・容量の差はまだ適用しない。
現在の曲線最小半径25mは全種類共通の暫定条件。通常40‰・高速30‰の勾配案は、
高さ・縦断モデルを実装後に敷設可否判定へ接続する。勾配で列車速度は変えない。
