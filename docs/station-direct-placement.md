# 駅の直接配置

- 建設 → 駅設置を選ぶと配置状態になる。線路の一覧選択、位置スライダー、配置確定ボタンは使わない。
- マップ上のカーソルから20画面ピクセル以内で最も近い建設済み線路または未着工計画を自動選択する。近い線路が不正な場合、遠い線路へ黙って切り替えない。
- ホーム形状は線路の曲線に沿う。線路端ではホーム全体が収まるよう中心を補正する。ホーム長は20m級車両の両数で指定する。
- ホバーはプレビューのみ、クリックで設置。その後も配置状態を維持する。ドラッグは地図移動で、駅を作らない。
- 地図をTabでフォーカスし、矢印キーで候補位置を移動、Enterで設置できる。Escapeは移動状態へ戻る。
- 駅名は端補正後の中心位置からローカル参照駅データを検索し、自動設定する。参照データがなければ「新駅」等の仮名を使う。
- 未着工線路上の駅はセッション内の計画に保持する。手動保存/自動保存には含めず、タブ移動・手動保存で消さない。ワールド読込/終了で破棄する。
- 自由描画の各計画、参考形状コピー、道路追従の計画に対応する。計画を着工すると線路と駅を同一トランザクションで構築する。参考形状の出典情報も維持する。途中エラーで一部だけ着工しない。
- 線形の編集後、計画駅の元の地理的位置が線路から外れたり長さが収まらない場合は、無効表示し着工を止める。線形を戻すか計画駅を削除する。勝手に別の位置へ移動しない。
- 計画駅にもCtrl+Z/Ctrl+Shift+Zが使える。線路ツールでは線形点の履歴が優先する。計画消去はその計画の駅のみを破棄する。
- 実際のWindows/WebView上でのポインター操作と画面表示は統合後に別途確認が必要。
