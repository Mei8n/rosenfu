# 未着工計画の保存・復元

2026-11-14の仕様変更で、以前の「計画はセッション終了時に破棄」を変更。手動保存と固定2分のオートセーブに未着工計画を含める。

- 建設済みワールドと同じファイル・同じ原子的書き込みで保存する。別ファイルによる世代ずれを作らない。
- 計画名、計画ごとの複数経路、計画駅、描画途中の点、点のRedo、線路種別・設計速度、延伸元、計画に追加済みの実在形状と出典を保存する。
- 読込時に選択中の計画・経路も復元し、次の計画・経路・駅IDを既存最大値より大きくする。
- 未着工の途中状態は完成線路の幾何条件を満たさなくても保存可能。型・座標・ID・計画内参照の破損は拒否する。
- ホバー、未確定の実在形状候補、駅・路線・系統・会社の未適用フォームは保存しない。参照候補は「選択中の計画に追加」で保存対象になる。
- schema 10を使用。旧schema 1〜9には計画がないため空の計画として開く。新しいセーブは旧アプリでは開けない。
- 手動保存成功後は保存済み計画だけを理由に終了警告を出さない。以後の編集・未適用フォームは警告する。自動保存は手動保存と別世代なので、手動未保存の警告を維持する。
- 保存失敗・読込失敗時は現在の編集内容を維持する。既存の排他・版照合・バックアップ・16 MiB保存上限を維持する。

検証: 複数計画・複数経路・駅・Redoの復元、計画だけを変更した自動保存、旧schema、保存失敗、既存バックアップ保護。
