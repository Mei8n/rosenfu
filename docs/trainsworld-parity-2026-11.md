# TrainsWorld 比較監査：Rosenfu 0.2.2

比較元: [Rosenfu `5fc8736`](https://github.com/Mei8n/rosenfu/tree/5fc8736470a7bb16bcfc639ba90204a098927a51)、[TrainsWorld 公開ソース `3e9c056`](https://github.com/circularsquare/trainsworld/tree/3e9c056469b7a87383c2211c30427fedfbbebe66/trainworld)、[作者の公開プレイガイド](https://anita.garden/projects/trainsworld/)。2026-11-25 JST。ソースおよび公開説明の比較であり、公開ブラウザ版のコミット同定・同条件での両製品実測は未実施。参考元のソース・データ・画像は取り込まない。個別の採否・実装スコープは既存の[ロードマップ](roadmap.md)を優先する。

| 領域 | 強み・弱みと確認対象 |
| --- | --- |
| 地図・実在網 | 両者とも実在網への追従を提供。Rosenfu は日本の地図・実在駅参照と既存ワールドのオフライン利用を独立に扱う。長距離の追従成功率、未取得領域の案内、地図パン時の応答は同条件未計測。参考元の「世界規模」を性能実測と扱わない。 |
| 線路・建設・駅 | Rosenfu は高さ・勾配、曲線、平行敷設、分岐、選択、Undo と独立した工事計画を実装。TrainsWorld の短い操作で実在線・平行線を建設する流れと、待避・折返し設備の案内は比較対象。標準ケースでクリック数とエラーからの回復を計測し、Rosenfu 固有の作図機能は残す。 |
| 路線・系統 | 起終点から中間駅を補う導線と別々の物理線・路線・系統は既存。Rosenfu も既存系統を複製できる。表示設定から「系統の操作」へ移し、削除と並べて見つけやすくした。既存の複製は物理経路・停車設定・関連する路線・表示設定を引き継ぐが、ダイヤや運転中の車両は引き継がない。TrainsWorld の停車順編集と、複製した系統をグループにまとめて表示する導線は別の比較項目。Rosenfu でも停車出現順が物理経路と一致しない場合に、順序だけを強引に変更しない。 |
| 運行・競合 | 参考元は列車が通る時刻を主に事前計算し、一部の曜日・便で追従と追越しの個別プロファイルも使う。Rosenfu は実行中の資源予約と後端解放を持つが、待避・ホーム・複数ダイヤ併用の適用条件が狭い。実予約を削除して見かけだけ揃えない。 |
| ダイヤ・車両 | TrainsWorld は時間帯ごとの編成数または目標間隔を直接設定。Rosenfu の時間帯指定は対象・期限が限定され、編成試算は運行に適用しない。最初に1往復を設定する手数、時間帯の連続性、目標に届かない理由、走行中の列車を壊さない更新で比べる。系統一覧の稼働中編成数と保有編成数は別。 |
| バス・トラム・船 | Rosenfu の踏切・道路追従は既存の道路データを利用。バス手動停留所・道路上トラムは検証済み形状に制約があり、一部の道路経路で復路やモード併用ができない。TrainsWorld の自動停留所・乗換点、広い道路経路、船とは差がある。比較対象であることと、船を今の配布版に入れることは別。 |
| 需要・流動 | TrainsWorld は用途別の実データ推計、混雑・時間・費用での経路選択、段階キャッシュとサービス変更時の再計算を公開。Rosenfu には固定ODの試算と観測再生があるが、同じ人口ベース・都市間性能や観測値ではない。全国自動生成・朝夕の需要方向変化は今の固定ODと混同しない。建設候補探索も旅客経路算定と分ける。 |
| 財務・経営 | 参考元の建設・運行費、利益・混雑の地図表示に対し、Rosenfu の財務と収支は未実装。稼働列車や仮の試算から実績の乗客数・収益を作らない。 |
| 保存・再開・大規模編集 | Rosenfu はファイル上のセーブ、オートセーブ、復旧、履歴に明示的な互換性を持つ。参考元は保存のバックグラウンド化などを記載。ロード時間、ピークメモリ、入力応答と確定処理を測定し、速度のために復旧・参照検証を撤去しない。 |
| 描画・表示設定 | 参考元は画面内の車両を分離して補間する。Rosenfu は2 Hzの運行スナップショットから形状が確認済みの車両に限り表示し、全体上限を画面範囲より先に適用するため、画面外の車両が表示枠を使う。視界優先と停止時・未対応形状を含む位置表現は別々に検証。ライト／ダーク・文字サイズ等の既存設定は保持。 |
| 共有・マルチ・配布 | TrainsWorld のブラウザ利用とコミュニティ共有は、Rosenfu のデスクトップ配布、オフライン、将来のプレイヤーホストとは異なる。非公開になっている参考元のサービス側実装は比較不能。QAは公開リリースではなく、再現可能な内部ビルドとして評価する。 |

## 同条件で先に再現するケース

- **運行**：単線対向、同方向の緩急（待避なし／あり）。停車・待機・通過・後端解放の時刻、運行が止まらないこと、所要時間とOD試算を別々に記録する。ケースごとにセーブ再開で同条件を再現する。
- **操作**：新規ワールドで線路・駅→路線→系統→運行、途中駅を変更→Undo、路線・系統を切替。操作回数、誤操作時の復旧、キーボードのみで操作可能かを記録する。
- **実道路**：バス2停留所→途中停留所追加→運行、道路上トラム建設→運行、セーブを開き直す。タイル取得不能、経路拒否、走行不能を別々に記録する。
- **性能**：実用的な小規模と大規模な同一データを固定して、入力応答、エンジン確定、地図描画、保存・再読込を分離する。測定なしに「軽くなった」としない。
