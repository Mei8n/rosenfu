# 駅の水域判定

駅の新設およびホーム寸法変更時、または線形変更で駅の中心または高さが変わる場合は、物理ホームの中心座標とその位置の実高度を検査する。地上（高度0）の中心が水域なら拒否する。高架・地下にはこの駅固有の拒否条件を適用しない。単独配置の旧方式駅は地上として扱う。

ホーム矩形の水域面積率やホーム全長を駅固有の水域条件にはしない。ただし、線路自体の水域条件、ホームの平坦性・重複・経路参照の保護は別に維持する。延伸により線路端に収めるため駅中心が移動した場合は移動後の中心を使う。駅舎建物の条件とは別である。

同じ構築モデルを駅単体の追加・寸法変更・計画のプレビュー/着工に使い、拒否時は世界とIDを更新しない。必要な登録済み水域データが未取得・不正の場合は陸とみなさず保留する。登録範囲外の正常な粗密選択は既存の全国水域モデルに従う。

既設駅の読込、駅名だけの変更、水域データの入替だけで既設駅を遡及拒否しない。新しい物理的編集は検査する。セーブ形式は変更しない。

## 参照と確認範囲

TrainsWorldの公開一次コード [net.rs の check_station](https://github.com/circularsquare/trainsworld/blob/6b8ef91729e1e5812f3dcbaedd6c0a49fed6a84b/trainworld/sim/src/track/net.rs#L2356-L2411) の中心点/地上判定を挙動の参考とした。コードの転用はしていない。線路の水域判定や駅舎建物の判定とは区別した。一次コードの静的確認であり、公開ゲームでの実操作再現を意味しない。

Rosenfuの単体・セッションテストは陸/水、実高度、未取得、ホーム面積と中心の違い、寸法変更、既設不変、拒否の原子性を対象とする。ネイティブGUIの受入確認は別途必要。
