# α0.2: 接続済みの直線複線における競合

両側とも2点1区間、同じ高さ・線路属性、接続座標が同じで水平面の接線が逆向きに一直線の普通複線では、既存の物理レーン対応が一対一で、通るレーンが確認できる場合に限り、接続部もレーン別に予約する。別々のレーンを使う対向列車は駅間を進める。同じレーン、単線、複線から単線への絞り、分岐、曲線・勾配など確認対象外の接続は従来の競合判定を保つ。複々線や信号・待避設備の追加ではない。

新規運行設定でこのレーン別予約を使ったセーブには `parallel_join_lanes` が入る。旧セーブの実行中の予約は読込時に書き換えない。条件を満たさなくなる編集後は該当運行を停止して再設定を求める。新しい予約を持つセーブを、このフィールドを知らない旧ビルドに戻して読み直すことはできない。戻す場合は更新前のセーブを使う。

駅間をまとめて予約する基本モデルや、ホームの収容力・閉塞ごとの追従・実際の踏切制御はこの変更の対象外。
