# α0.2 運行の初期スライス

- Rust が共通経過時刻を管理。UI は進行の wake を送るだけで、クライアント時計を採用しない。停止・1/2/4/8/16倍。
- 簡易ダイヤは絶対経過ミリ秒の始発・終発（inclusive）・間隔。24時間を超えられる。曜日・祝日・反復日別ダイヤは未実装。新規設定では、物理的に同じ単線レーンで向きを変え、逆方向の接続も成立する終点に限り、同じ列車が停車時間と後端通過の両方を待って1回だけ折り返す。既に閉じた経路や、往復で異なるレーンになる複線ホームでは自動折返ししない。複線上の直接の渡り線経由は未実装。通常の複線から明示的な2→1の分岐器で、停車位置と車両長が収まる単線の終端線へつながる構成では、1系統だけの簡易ダイヤに限り、同じ車両がホームと分岐器を確保してから反対側の線路へ折り返す。後続列車は折り返した列車の後端が空くまで待つ。この運行を使うセーブだけ新しい形式（ワールド33／内部運行8）となり、旧版では開けない。併用軌道の道路根拠を持つワールドの新規設定では従来の占有方式を維持する。ワールド33の運行をすでに使っていて併用軌道を追加する場合は、先に運行をリセットする必要がある。同じセーブで時間帯ダイヤ・バス運行・他の予約拡張と組み合わせない。他の形式の運行や従来の片道セーブは自動変更せず、そのまま再開する。
- 実系統の停車参照と物理線形から停車点間距離を生成。通過駅では停止しない。短距離の加減速と線路・車両・分岐速度上限を反映。勾配で速度を下げない。
- 初期距離は線形中心線で計測。分岐器は実装済み曲率速度を保守的に適用するが、個別軌道曲線長による厳密な距離補正は未実装。
- 占有は停車点間に含まれるアンカー区間を一括予約。単線は双方向で共用、複線/複々線は方向別1レーンを使用。分岐点資源は排他。後端の通過後に解放。限定直線複線の後端通過による手前区間解放、終点・中間停車中のレーン保持、明示経路の小規模待避線（内部形式3/5/6/7）は[占有モデルの仕様](parallel-join-occupancy.md)を参照。一般的な閉塞追従・待避線の自動選択・駅グループの収容力は未実装。
- 短い直線・地上・単線の独立線形（1〜2本）だけで、平面の長さ十分な終端ホームが両方とも予約範囲内にまるごと収まる場合は、終点で停車中も往路の区間を予約したまま同じ列車で復路に入り、復路の後端通過まで競合列車を待たせる。この折返し保持の対象外では、この方式を適用しない。対応する運行保存内形式は4（外側 schema27）。形式4を読めない旧ビルドに戻す場合は更新前のセーブを使う。ホーム別容量や閉塞解放を追加したものではない。
- 新規運行設定では、明示的な接続を持たない局所的な平坦2点直線の通常単線同士のみ、同じ高さで内点交差したときに交差点ごとの予約を追加する。経路同士を接続せず、対象地点を通る運行だけが既存の停車点間予約・後端通過まで競合する。高さ差がある立体交差、平行線、非対象の曲線・勾配・接続線・複線・トラムにこれを適用しない。候補比較32,768件、またはダイヤ全体の交差予約参照16,384件の上限を超えた新しいダイヤは適用せず既存設定を維持する。停車するホームが交差に近く、車両が停車中に交差から抜けたと確認できない場合も、新しい運行設定を適用しない。閉塞信号や正確な交差点占有時刻の実装ではない。
- 交差予約を含む保存状態には保存済みの予約モデルを示す印を付け、該当線形・ダイヤから再検証して再開する。従来の交差予約を持たない保存状態はそのまま開き、走行中に新しい予約を追加しない。対象形状を変更して既に保存した交差予約を再検証できないときは、従来の運行無効化と同様に停止・再設定を要求する。交差予約の印を含む保存は、印に対応しない従来版では読み込めない。旧版へ戻す場合は更新前のセーブを使う。
- 衝突事故は扱わず、他列車が占有中は待つ。イベント処理予算を超えた場合は未処理時刻目標を保持し、列車を捨てない。 鉄道の運行欄では、発車できる時刻を過ぎても予約に阻まれている場合、原因を確認できたものに限り、平面交差・分岐/接続・線路のいずれかを表示する。複数の競合がある場合は現在の一因であり、ホームの収容力や設備の不足を診断する表示ではない。
- 運行開始後でも、一時停止中で走行・停車・進路待ちの車両も未処理の運行もない時は、自社の鉄道・バスのダイヤを個別に変更・追加できる。時刻、倍率、他のダイヤ、記録した固定OD条件を残し、処理済み時刻までの便は再生成しない。始発・終発は従来どおり絶対時刻で、開始済みのワールドでは現在時刻と同時刻の便も通過済みとする。対象を含む全ダイヤを現行経路で検証し、無効な参照や古い画面からの競合入力は適用しない。開始済みの場合は既存の占有方式を維持し、他系統の経路や予約対象を変える変更は個別適用しない。
- 一時停止中に限り、既存の鉄道系統は車両が残っていても今後の発車時刻だけ変更できます。指定時刻のうち処理済みの現在時刻を含む過去の発車は追加せず、既に発車した列車・進路予約・停車時間・他系統は変更しません。前のダイヤで発車した列車がまだ残る間は、同じ系統の再変更を拒否します。少なくとも1便の将来の発車が必要です。未処理時刻がある、運行が無効、または再生中の場合も変更できません。バスや車両・停車時間の変更は全車両がいない時間帯の一時停止が必要です。
- この操作で前のダイヤの列車が走っている間のセーブには、元の発車時刻を検証する切替情報を保持します。切替情報が必要な間は時刻欄に旧ビルドで開けないことを表示します。最後の該当列車が退場すると不要な情報と警告を取り除きます。すでに切替中に保存したファイルを旧ビルドに戻す場合は、対応版で切替が終わってから保存し直すか、切替前のバックアップを使ってください。以前のセーブを読む時は自動切替しません。自動で新規発車だけを止める機能、定期的な時間帯別ダイヤ、車両数の自動割当はこの変更に含みません。明示的な「運行をリセット」は引き続き時刻・鉄道とバスの全ダイヤ・列車を消去する。線路/駅/路線/系統・固定OD条件は残す。
- 運行を設定した系統の経路・停車駅を変える場合は、**変更を適用する前に**全車両が運行を終わるまで進め、一時停止する。いまのダイヤと占有方式を保って再検証できた場合だけ、同じ時刻で経路/停車設定と運行を一緒に適用する。できない場合は入力と現在の運行を残す。この変更を元に戻す・やり直す場合も、運行に影響するときは同じ条件で処理し、拒否しても履歴を消費しない。名前だけの変更や、運行に影響しない系統の編集にはこの制限をかけない。
- 線路/速度などの建設編集やUndoはこの適用ガードの対象外で、運行が無効化される場合がある。無効化済みの車両は自動で消去・再開しない。編集Undoは運行履歴とは独立。
- schema27 の別 envelope に運行状態を保存。長時間の歴史を再演せず現在列車・次発時刻を復元。旧schema26 は読込でき、旧schema25以前は非破壊で非対応。別ワールドに運行状態を持ち越さない。
- 固定OD UI はユーザー入力の仮定人数と代替時間を実ダイヤの予定所要時間へ配分する試算。実人口・実利用人数・運賃・収入ではない。既定の計画試算には実際の占有遅延を反映しない。鉄道だけの短時間試算は[固定ODの遅れを含む試算](alpha02-fixed-od.md#運行の遅れを含む短時間試算)を明示的に実行する。
- バスは検証済み道路グラフまたは明示的な合成QAグラフの停留所間距離を使用。同じ時計・待ち・保存・ODに接続。仮定速度1〜120km/hはゲーム設定であり実道路の法定速度ではない。自動車交通量・信号待ち・ライブ道路の通行権限推定は未実装。
- 地図上の運行位置は、根拠を確認できる限定区間のみ表示する。列車は接続のない地上直線単線。通常のバスは保存済みの往路で、隣の停留所まで同じ地上直線道路片だけを走行している場合、または往路全体が16道路片以内の往復系統で該当区間の地上経路と走行距離を確認できる場合が対象。描画のために地図を再取得・再探索せず、確認済み経路がメモリにない場合は点を表示しない。復路は、終点から起点まで途中停車せず、確認済みの独立した地上経路が16道路片以内の場合に、その復路を表示する。進路待ち・停車中や、途中停車を含む復路などの対応外区間には点を表示しないが、運行は変わらない。専用サーバー自律tickは未実装。

## 同じ道路区間の途中にバスの起終点を置く

建設 → バス → 「道路の途中に起終点を置く（片道）」を選び、
同じ地上道路の一区間上を2か所クリックします。交差点や複数の区間をまたぐ
作成には、従来の「新しいバス系統」を使ってください。一方通行の設定を保持します。
距離が表示されても、確定ボタンを押すまで系統や停留所は追加されません。
この操作で置く停留所はゲーム用です。現実の乗降や通行可否は示しません。

片道の区間系統は従来のダイヤで運行できます。途中停留所、復路、
時間帯ダイヤ・複数の地図区画をまたぐ併用軌道・新しい専用の鉄道運行方式とは
併用できません。1つの地図区画の道路に沿う路面電車は、通常の運行方式で併用
できます。バスと路面電車の相互の渋滞や信号待ちは計算しません。
このバス系統を含むセーブは形式34。道路に沿う路面電車も含む場合は複合形式35とし、
保存ヘッダーの機能一覧を実際に保存した道路とダイヤの組み合わせと照合します。
いずれも旧版では開けません。対応外の形式は旧セーブや自動保存で上書きしません。
通常のバス系統は従来どおりです。

地上の複数の道路片にまたがる場合も、通常の運行方式で片道の途中起終点を
設定できます。この方式は別の確認済み経路として複合形式35に記録します。
途中停留所も選んだ道路上に追加できます。復路はこの方式では未対応です。
同じワールドに併用軌道を置けます。バスと路面電車を同時に動かす場合は、
実際の運行区間が十分に離れていると確認できる必要があります。道路を共有する
列車とバスの相互の渋滞・信号・優先制御はまだ行いません。


独立した通常バス1系統と専用折り返し鉄道1系統を併用する場合、道路と線路の
経路・予約が物理的に独立していることを確認できた構成だけ同じ複合形式35を使います。
地図区画3〜4個の道路に沿う路面電車もこの形式を使い、他の種類と同じ機能扱いには
しません。それぞれ実際の証拠に対応する機能一覧が正確にある場合だけ再開します。


## 運行の待ち・乗換試算（人数指定なし）

都市タブで鉄道の乗車駅と降車駅を指定すると、実行状態のコピーから現在のゲーム時刻以降30分だけ再現し、競合待ちによる出発・到着の変化も含めた1人分の最早到着経路を表示する。出発駅には現在時刻に到着した前提。同じ駅IDでの乗換のみ、乗換余裕1分。乗換余裕は駅での待ちに含め、続けて同じ列車に乗る場合の停車・待ち時間は車内時間に含める。予定の半間隔や累積遅延を二重加算しない。

上限（256イベント、64列車、小規模経路）に達した場合は未確定とし、30分内に到着がなければ以降は未確認と表示する。開始前に出発した列車には途中から乗ったと仮定しない。バス／駅間徒歩・実旅客配分・実測交通は未対応。予定ダイヤを使う固定ODの結果、時計、現在の列車、保存形式は変更しない。

## トラム専用線と通常・高速線の接続

同じ所有者・高さ・勾配・接線の条件を満たせば、トラム専用線と通常・高速線を**別区間のまま**接続できる。接続点にホームが掛かる場合は着工・駅設置を拒否する。系統の実際の停車駅のうち一つ以上がトラム専用ホームなら、鉄道線とトラム線を通る系統にできる。未選択の通過駅や、別のホームが同じ駅グループに入っているだけでは条件を満たさない。トラム専用線を通る経路から最後のトラム停車を外す操作は適用しない。

混在系統の最高速度は75 km/h。線路・分岐・車両の上限がこれより低ければ低い方を使う。既存のトラム専用線の設計速度と保存規則は変えない。共用区間では普通列車とトラムの進路予約が競合する。平面交差の新たな信号予約、専用のトラム車両保有数、走行車両の地図表示はこの変更に含まない。


## 編成数と運転間隔の試算

既に運行設定があり、両端で同じ物理レーンに戻れる往復系統だけが対象。往復の走行時分に、各停車および両端での折り返し準備時間を加える。停車と後端の通過時間は重複して足さず、長い方を使う。発車間隔を指定した場合は「往復時間÷間隔」の切り上げ、編成数を指定した場合は「往復時間÷編成数」をミリ秒単位で切り上げる。

これは競合しない場合の目安で、実際にその間隔で運行できる証拠ではない。既存ダイヤ、車両数、資金、セーブを変更しない。片道、任意の環状系統、別レーンでの折り返し、ピーク別設定、線路容量、合流の間隔調整や端末の調整停車は対象外。設計は[TrainsWorldの台数・間隔設定](https://github.com/circularsquare/trainsworld/blob/50f7b159f139c1abb6dfaea43a1aea22f55281af/trainworld/docs/track-and-service.md#L1374-L1473)を参考にしたが、容量に応じて編成・間隔や実発車を変える同等機能を実装したわけではない。


## 時間帯ダイヤとバスを同じワールドで使う場合

対象は走行中・停車中・待機中の車両や未処理時刻がない一時停止中のワールドで、
既存の固定占有（運行内形式2）を使う場合。時間帯ダイヤを使う1鉄道系統と、
設定済みの通常ダイヤ（バスを含む）を合計4系統まで併用できます。時刻を戻したり、
既存バスの次の発車を変更したりせず、鉄道側だけ時間帯ダイヤを適用します。
運行中のダイヤ再編、バスの時間帯設定、両モードを横断する時間指定ODは対象外です。

**時間帯ダイヤとバスを併用中に保存したファイルだけ、外側の保存形式は schema28 です。**
従来のダイヤや鉄道のみの時間帯ダイヤでは schema27 のままで、自動移行はしません。
従来の0.2.1では schema28 を読み込めません。切り替える前のセーブは別に保管してください。
この互換性の制限は手動保存・オートセーブの両方に当てはまります。


### 時間帯ダイヤの途中駅から固定ODを試算

選択した1系統の往路で、実際に停まる乗車駅と、それより後に停まる到着駅を選びます。
途中駅の発車枠は起点の発車枠を、そこまでの予定走行・停車（後端通過と重複しない）分だけ
ずらして求めます。利用者が乗車前に過ぎた停車時間は乗車時間に足しません。
試算範囲の開始は含み、終了は含みません。乗車駅に対応する有効範囲の外を含む場合は、
発車ゼロではなく未確認です。この試算は予定だけを使い、競合遅れ・復路・乗換を推定しません。


### 有効な時間帯ダイヤの頻度を変更

同じ系統の既に適用した基本間隔・朝夕などの間隔を「時間帯ダイヤを変更」から調整できます。
全車両の運行が終わり、未処理の時刻がなく、一時停止しているときだけ適用できます。
新しい設定は現在から少なくとも1分先の分境界から24ゲーム時間有効です。旧設定の今後の発車は、
新設定の開始を待つ間の便も含めて置き換えます。過去の便を走らせ直さず、
時刻・車両設定・他の鉄道やバスのダイヤ・記録済み固定ODには触れません。
時間指定の固定OD試算には現在の設定を使います。旧設定での比較結果は保存しません。
