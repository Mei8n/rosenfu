# α0.2 運行の初期スライス

- Rust が共通経過時刻を管理。UI は進行の wake を送るだけで、クライアント時計を採用しない。停止・1/2/4/8/16倍。
- 簡易ダイヤは絶対経過ミリ秒の始発・終発（inclusive）・間隔。24時間を超えられる。曜日・祝日・反復日別ダイヤは未実装。新規設定では、物理的に同じ単線レーンで向きを変え、逆方向の接続も成立する終点に限り、同じ列車が停車時間と後端通過の両方を待って1回だけ折り返す。既に閉じた経路や、往復で異なるレーンになる複線ホームでは自動折返ししない。渡り線経由の折返しは未実装。従来の片道の運行データはそのまま再開する。
- 実系統の停車参照と物理線形から停車点間距離を生成。通過駅では停止しない。短距離の加減速と線路・車両・分岐速度上限を反映。勾配で速度を下げない。
- 初期距離は線形中心線で計測。分岐器は実装済み曲率速度を保守的に適用するが、個別軌道曲線長による厳密な距離補正は未実装。
- 占有は停車点間に含まれるアンカー区間を一括予約。単線は双方向で共用、複線/複々線は方向別1レーンを使用。分岐点資源は排他。リアクリアランス後に解放。閉塞ごとの追従・待避線進路選択・駅ホーム容量は未実装。
- 衝突事故は扱わず、他列車が占有中は待つ。イベント処理予算を超えた場合は未処理時刻目標を保持し、列車を捨てない。
- 開始後のダイヤ変更は明示的な運行リセット後。リセットは時刻・運行設定・列車を消去するが線路/駅/路線/系統を消さない。
- 経路/速度/停車点変更は既存の時計を巻き戻さず運行を無効化・停止。再設定前は再開不可。編集Undoは運行履歴とは独立。
- schema27 の別 envelope に運行状態を保存。長時間の歴史を再演せず現在列車・次発時刻を復元。旧schema26 は読込でき、旧schema25以前は非破壊で非対応。別ワールドに運行状態を持ち越さない。
- 固定OD UI はユーザー入力の仮定人数と代替時間を実ダイヤの予定所要時間へ配分する試算。実人口・実利用人数・運賃・収入ではない。実際の占有遅延は需要配分には未反映。
- バスは検証済み道路グラフまたは明示的な合成QAグラフの停留所間距離を使用。同じ時計・待ち・保存・ODに接続。仮定速度1〜120km/hはゲーム設定であり実道路の法定速度ではない。自動車交通量・信号待ち・ライブ道路の通行権限推定は未実装。
- 列車/バスの地図上補間表示、専用サーバー自律tickはこの初期スライスでは未実装。
