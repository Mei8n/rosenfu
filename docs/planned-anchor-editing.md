# 計画アンカーの編集

未着工の手描き線路のアンカーをドラッグして移動できます。途中点では隣接する2区間、始点・終点では隣接する1区間を変更します。対象外の区間は保持します。線路を描き足すときは編集済みの終端接線に続けます。

- 白/桃色の小さな四角をドラッグします。表示より広い22pxの当たり判定があります。
- 他の計画のアンカー・既設線路の端点は14px以内、線路上は6px以内で吸着。吸着時は緑色のリングです。これは**位置合わせのみ**で、線路途中の分岐や他の線路との接続設備を作りません。既設線路を延伸する場合は従来の端点から描く操作を使用します。
- 自身のアンカーへの吸着はしません。隣点との重複、25m未満の推定曲率半径、折返し、範囲外、4096点を超える線形は確定しません。
- 既設線路への延伸元となる始点は移動不可。実在線路/道路から取得した参照形状は由来情報を守るため移動不可。建設済み線路そのものは変更しません。
- ドラッグ中はプレビューだけ。離して正常な形なら確定します。Esc、pointercancel、capture喪失、ツール/画面切替は取消。Ctrl+Z / Ctrl+Shift+Zでアンカー移動をUndo/Redoできます。
- 計画駅を自動削除・自動移設しません。線形から外れた駅は無効表示となり、着工を止めます。Undoで線形を戻すか、駅を置き直してください。

## 幾何と保存

既存の円弧生成方式のアンカーを後から一括再解釈しません。初回編集時に現在見えているsampled lineを基準に、隣接区間の弧長に沿うsmoothstep変位で局所変形します。外側の点と接線を保持します。これは完全な円弧・測量形状ではなく暫定の編集モデルです。区間速度もサンプル点列の局所曲率近似から算出し、設計最高速度を上限とします。

保存schemaは12。計画のoptional `editedGeometry`、作図中のoptional `draftEditedGeometry` に `{version:1, anchors, line}` を保存し、そのまま復元します。従来schema1〜11も読み込み可能で、編集していない既存形状は変更しません。schema12保存は古いアプリでは読めません。従来と同じ保存バックアップ方式を使用します。ドラッグ中の未確定previewは保存しません。

編集のUndo/Redoは現在の作図作業の履歴です。点追加とアンカー移動はその順に戻せます。別経路への切替・新規経路・着工・読込・下書き消去ではアンカー編集履歴を終了します（計画の形自体は保持）。保存ファイルに操作履歴は保存しません。
