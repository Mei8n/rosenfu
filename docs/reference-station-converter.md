# ローカル OSM 駅ポイント変換ツール

`scripts/convert-osm-stations.mjs` は、利用者が事前に適法に取得した小地域の OSM 由来 GeoJSON を、実在駅参照レイヤー用 JSON に変換する試作 CLI です。Node.js 24 だけで動き、追加依存やネットワークアクセスはありません。データの取得・アップロード・地名照会は行いません。

**実在駅データは同梱していません。** テスト内の座標・名称・ID は架空の fixture であり、実在駅として使わないでください。変換結果を読み込んでもゲーム内の駅や路線は追加されません。背景地図のオフライン保存や線路スナップとは別機能です。

## 入力条件

- UTF-8 の GeoJSON `FeatureCollection`。入力は 50 MiB 以下の通常ファイル。FIFO・デバイス・ディレクトリは拒否し、読込中にファイルが増えても最大サイズを超えて読み続けません。
- `railway=station` または `railway=halt` の `Point` のみを収録します。`tram_stop`・ホーム・出入口・`stop_position` 等は対象外です。
- タグは `properties.railway` 等の平坦形式、または `properties.tags` にまとめた形式を使えます。
- OSM ID は `feature.id` または `properties["@id"]` に、`node/123`・`way/456`・`relation/789` の文字列で指定します。両方ある場合は同一値が必要です。数字部分は先頭ゼロなしの正整数 1〜20 桁。数値型 ID は精度や種別が不明なため受け付けません。
- 名称は `name:ja` を優先し、なければ `name` を使います。空名や 200 文字超はエラーです。独自の地名を補完しません。
- 面や relation 由来でも **既に Point 化され、元 OSM ID が維持されているもの** は入力可能です。代表点の品質・算定方法はこのツールでは確認しません。
- 非 Point の駅は、代表点を捏造せず警告付きでスキップします。全駅が Point になっていることや地域の駅網羅性は保証しません。

非駅地物と対象 bbox 外の地物は件数を報告して省略します。bbox 内の駅に不正 ID・重複 ID・不正座標・不正名があれば、変換全体を拒否して出力しません。近接位置や同名を理由に駅を統合しません。

## 実行

リポジトリ直下で実行します。以下のファイル名、地域 ID、データ日時、範囲、出典は、自分の入力データに合わせて置き換えてください。

```sh
node scripts/convert-osm-stations.mjs --input stations.geojson --output station-pack.json --id my-region --revision 2026-11-12 --bounds 135.3,34.5,135.7,34.9 --source "OpenStreetMap; original download URL and extraction method" --license ODbL-1.0
```

- bbox 順序は `西端経度,南端緯度,東端経度,北端緯度`。緯度は Web Mercator の範囲（±85.05112878°）内、日付変更線またぎは未対応。
- bbox はデータの対象範囲を示します。駅位置の最小・最大から自動推測しません。データがない部分を「駅が存在しない」とみなすことはできません。
- `--revision` は実際の元データ日時・版を指定します。実行日を元データ日として自動付与しません。
- `--source` に取得元・抽出方法を記録してください（1,000 文字まで）。CLI は出典やライセンス宣言の正しさを検証しません。
- 出力は新規ファイルのみ。既存ファイルの上書きや入力ファイルの置換は拒否します。必要なら別名で生成してください。
- 出力は参照レイヤーの上限に合わせて 5 MiB・20,000 駅以下。上限を超えた場合は切り捨てず拒否します。範囲を小さくして再実行してください。
- 成功時は件数・省略理由・警告を標準エラーへ JSON で出力します。警告詳細は最大 50 件、件数は全件を集計します。エラー時の終了コードは 1。

できたファイルは地図設定の実在駅参照パック読込から選択します。検証済みパックは端末のIndexedDBへ保存され、次回起動時に再検証して復元します。保存できない環境では失敗を明示し、セッション内で利用できます。元のJSONは保管してください。

## 出典・配布と制限

OSM データの使用には [ODbL と帰属要件](https://www.openstreetmap.org/copyright) が適用されます。元データの提供条件や、変換した派生データベースを配布する場合の義務も確認してください。帰属を表示しただけで全ての再配布条件を満たすとは限りません。

元の配布ファイル・取得元 URL・データ日時・抽出条件・代表点生成方法は、出力パックと一緒に記録しておくことを推奨します。変換ツールはライセンスを付与・変更せず、ユーザーの宣言を保存するだけです。

[OSM 標準タイル配信](https://operations.osmfoundation.org/policies/tiles/)の一括取得はこの用途では使いません。背景画像をスクレイピングして駅データへ変換する機能もありません。GeoJSON の駅ポイントだけでは道路・線路の接続関係を得られず、駅スナップや走行グラフの原本にはできません。

## 検証

```sh
npx vitest run scripts/convert-osm-stations.test.mjs
```

UI の実際の参照パック parser で出力を読み戻すテスト、文字列 ID 保持、不正値・重複拒否、非 Point 省略、既存出力非上書きを含みます。実データの取得や地域別の網羅性検証は実施していません。
