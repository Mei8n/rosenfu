# 線路敷設UI（2026-11-13）

- 建設の線路ツールを選ぶと描画可能。曲線・直線、線路種類は地図上部の設定で切り替える。参考形状コピーの詳細は左側に残す。
- 左ドラッグは地図移動。クリックで点を追加し、終端ダブルクリックで現在の経路を終了する（まだ未着工）。そのまま次のクリックで独立した別経路を開始し、前の計画は保持する。
- 曲線モードは最後の点から8 CSS px以内を終端として扱う。ズーム・地図サイズに依存しない操作上の許容幅で、直線モードの既存追加判定は変更しない。
- 終了した計画は着工可能。「計画を編集」で選ぶとその終端から延長できる。Escは線路ツールを解除して移動に戻り、計画を破棄しない。再開は線路ツールを選ぶ。
- 描画中のカーソル情報は常時表示。既存計画の詳細はhover時のみ。ドラッグ中・ポインタが地図外に出た時には非表示。
- 不可候補は赤、確定済み下書きは青。折り返し等で円弧を計算できない場合の赤い線は診断用の直線であり、建設座標には使わない。不正なクリックは点を追加しない。
- 曲線毎の速度表示は [暫定ゲームモデル](provisional-curve-speed.md)。画面上のラベルは固定サイズで、密集時は最新の曲線を優先し重なりを間引く。
- 費用・高さ・複線等未実装の数値や操作は追加しない。種類別の規格差も未実装で、説明から確認できる。
