# 線路敷設UI（2026-11-13）

- 建設の線路ツールを選ぶと描画可能。曲線・直線、線路種類は地図上部の設定で切り替える。参考形状コピーの詳細は左側に残す。
- 左ドラッグは地図移動。クリックで点を追加し、最後の点をもう一度クリックして現在の経路を終了する（まだ未着工）。そのまま次のクリックで同じ計画内に独立した別経路を開始し、前の経路も保持する。
- 直線・曲線とも最後の点から8 CSS px以内を終端として扱う。ズーム・地図サイズに依存しない操作上の許容幅。直線そのものの幾何計算は変更しない。
- 終了した計画は着工可能。「計画を編集」で選ぶとその終端から延長できる。Escは線路ツールを解除して移動に戻り、計画を破棄しない。再開は線路ツールを選ぶ。
- 描画中のカーソル情報は常時表示。既存計画の詳細はhover時のみ。ドラッグ中・ポインタが地図外に出た時には非表示。
- 不可候補は赤、確定済み下書きは青。折り返し等で円弧を計算できない場合の赤い線は診断用の直線であり、建設座標には使わない。不正なクリックは点を追加しない。
- 曲線毎の速度表示は [暫定ゲームモデル](provisional-curve-speed.md)。画面上のラベルは固定サイズで、密集時は最新の曲線を優先し重なりを間引く。
- 費用・高さ・複線等未実装の数値や操作は追加しない。種類別の規格差も未実装で、説明から確認できる。

- 終了判定は直線・曲線とも最後の点から8 CSS px以内。ダブルクリックの時間間隔には依存しない。終了後の同じ連打は追加点にせず、次の独立したクリックで別経路を開始する。

- 描画終了後または点のない状態で、選択中の計画内の未着工経路の末尾をクリックすると、その経路の続きへ戻る。再開クリック自体は点を追加せず、計画駅とUndo/Redoを保持する。始点側からの再開・着工済み線路の延伸は未対応。

## 計画と経路

- 計画は任意の名前を持ち、1つの計画に複数の独立経路を含める。各経路は独立した点列・線路種別・Undo/Redo履歴を持つ。
- 計画を分けるのは「別の線路計画を追加」を押した時だけ。経路の描画終了では計画IDを変えない。
- 「計画を着工」は選択中の計画の全経路・全計画駅のみを原子的に着工する。いずれかが不正なら全て未着工のまま残す。他計画は着工しない。
- 「下書きを消去」は選択中の計画の経路と駅のみを消す。他計画は残す。
- 計画駅は計画IDではなく経路IDへ紐付け、別経路の編集や再開で移動しない。
- 参考形状コピーは既存の独立フローを維持し、自由描画計画との混在は今回対象外。

- 計画内の経路一覧から点数0（Redoのみ）や1点の未完成経路も再選択できる。未完成経路が残る計画は着工不可だが、経路を選んでやり直し・追記できる。
