# 独立した複数の線路計画

未着工の手描き線路を複数保持できます。経路が離れていても互いを接続しません。

- 現在の経路を描き、終端ダブルクリックで点追加を終えます。
- 「別の線路計画を追加」で現在の経路を保持し、空の計画を描き始めます。
- 保持した計画も同時に地図へ表示されます。番号付き一覧から編集対象を切り替えます。
- 曲線/直線の選択と点単位のUndo/Redo履歴は計画ごとに保持します。
- 計画名は任意（最大80文字）。一覧から対象を選んで変更できます。未入力なら「計画 N」と表示し、そのまま着工可能。路線名や建設済み線路名とは別で、再起動後には残りません。
- 着工、下書きの消去は編集中の計画だけに作用します。着工失敗時はどの計画も失いません。
- 全計画の一括着工ではありません。計画間の接続、分岐や交差の自動生成は行いません。

## 保存に関する制限

現段階の計画はUI内の一時データです。ワールドファイルの既存形式は変更していません。
未着工計画があっても建設済みワールドを保存できます。計画は保存対象外ですが画面上に残り、読込には破棄確認を表示します。駅設定・会社・路線・系統の未適用編集は、従来どおり手動保存前に適用または破棄が必要です。
アプリを閉じると計画は失われるため、画面内にも明示しています。
再起動をまたぐ計画保存・復元は未実装です。着工後の線路は通常のワールド保存対象です。

## 検証

`npm test -- src/IndependentPlans.test.tsx`:
互いに離れた計画の同時表示、切替、個別着工、失敗後保持、Undo/Redo、個別消去、読込確認を確認。
Windows実機での操作確認は別途必要です。

### 終了確認

未適用の計画または未保存の変更がある場合、ブラウザの `beforeunload` と
Tauri のウィンドウ終了イベントをガードします。Tauri では「編集に戻る」または
「破棄して終了」を選びます。イベント登録が失敗した場合は警告を表示します。
これは保存・バックアップではなく、強制終了・クラッシュ・OS終了の全ケースを保証しません。
Tauri の実機での終了イベントは別途確認が必要です。
