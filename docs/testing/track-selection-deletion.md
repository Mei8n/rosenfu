# 線路の選択・削除の確認

この文書の従来手順は全体削除のみだった時点の記録です。開発版 `fae55f3` には区間削除・Redoが追加されているため、現行の受入は[0.1受入](../alpha-0.1.md)を優先してください。未着工計画と建設済み設備は別々に検証し、他の設備を連鎖削除しないことを確認します。

## 優先する回帰確認

1. 専用テストワールドで途中区間を選択し、Enterで削除を確定する。
2. Ctrl+Zで戻し、Ctrl+Shift+Zで同じ区間を再削除する。残存線形・対象外駅・接続が変わらないこと。
3. 未着工経路でも確認し、残る前後区間の形状・駅・計画所属を確認する。
4. 計画切替を挟んでも別計画の編集を巻き戻さないこと。
5. 保存・再読込で削除後の構造が維持されること。Undo履歴の再起動保持は削除結果の永続化とは別に確認する。
6. 路線・系統等が参照する設備への禁止操作は拒否され、失敗時にも編集中のデータが維持されること。

基準版の自動試験とネイティブGUI合格は別。操作対象と結果を対象SHAつきで記録する。元のセーブは別途退避し、単一保存スロットの上書きに注意する。
