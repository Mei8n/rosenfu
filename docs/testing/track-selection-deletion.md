# 線路の選択・削除の確認

対象は新方式の建設済み線路（Alignment）全体と、未着工計画の個別経路。
線路の一部分を切断する操作や分岐削除は含まない。

1. 地図の「選択」を押し、建設済み線路または計画中の線路をクリックする。
2. 対象表示を確認し「選択線路を削除」を押す。確認画面でキャンセルすると変更しない。
3. 確定すると選択した線路だけが消える。他の経路や計画は残る。
4. 「線路削除を元に戻す」で直前の削除を取り消す。
5. 保存・再読込で、削除を含む状態が維持されることを確認する。

安全制約:
- 建設済み線路を使う駅、路線、系統、延伸計画、駅計画があれば削除を拒否する。
- 計画線路に計画駅があれば削除を拒否する。駅などを連鎖削除しない。
- 取消履歴は現在の実行中のみ、直前1回分。別の編集・読込があれば復元で上書きしない。
- 削除は保存するまでディスクのワールドに反映されない（自動保存は別ファイル）。
- 旧方式の駅間線路は既存の設備削除UIを使用する。
- GUI実機での操作感は未検証。自動テストは選択・取消・確認・依存保護・保存を確認。

実装: Rust側でも依存・自社所有・保存可能性を検証し、成功時だけ状態を交換する。
取消は削除直後のスナップショットとの完全一致を要求し、後続の編集を巻き戻さない。
