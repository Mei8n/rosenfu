# 参照形状と延伸区間の出典

保存形式 schema 9。schema 1〜8 は読込時に移行し、元ファイルは保存するまで変更しない。
旧出典は元線形の点0から最終点までを指す範囲に変換する。

`alignment_provenance` は線形IDと点範囲（start_point_index / end_point_index、両端を含む）で参照由来部分を表す。
同じ線形に複数記録を許す。区間は端点を共有できるが辺の重複は禁止。
範囲外はその出典に帰属させない。手描き延伸で元OSM由来範囲を拡大しない。
始点延伸では既存範囲を点数分ずらし、新たな参照区間は点列と同時に元区間の向きも反転する。
出典スナップショット・ライセンス・帰属表示は全件保持し、参考バンドル除去後も消さない。

一般のreplaceによる既存出典・元形状の変更禁止は維持。
専用延伸だけが既存点列をそのまま残すことを確認し、出典範囲を更新する。
系統が使用する既存駅座標・経路・停車駅参照も保持する。
`build_plan` は reference と extension の共存を受け付け、駅も含む全計画をatomicに適用する。

参照情報は未信頼のスナップショット。ハッシュは元データとの整合識別であり真正性・精度・権利を保証しない。
入力形状は従来同様に呼出側で参照バンドルと照合する。複数way経路探索や分岐の実装ではない。

## 参照経路の計画と端点吸着
参照区間は直接着工せず「選択中の計画に追加」で経路として保持し、手描き経路・計画駅と一括着工する。追加後の参照経路の形状編集は固定し、出典と形状の対応を壊さない。
参照延伸対象は、選択した起点から8 CSS px以内の既存端点の中から明示選択する。元の参照セグメントに対する端点のfractionを再計算し、元座標からその既存端点を正確に再現できる場合のみ候補にする。近くの並行線路や参照形状外の端点へ移動・変形させない。選択後はプレビューと送信するsource fractionの両方を補正する。複数候補からの自動接続はしない。
