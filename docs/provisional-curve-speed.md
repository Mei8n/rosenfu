# 曲線制限速度の暫定表示

手描き円弧の情報ラベルは、Rosenfu の初期ゲームバランス用モデルとして
`floor(3.6 * sqrt(半径 m * 1.5 m/s²))` km/h を表示する。
横加速度の仮定は 1.5 m/s²。半径 25 / 100 / 300 / 500 / 1000 / 2000 / 8000 m はそれぞれ
22 / 44 / 76 / 98 / 139 / 197 / 394 km/h となる。

これは実際の列車速度、鉄道の安全基準、TrainsWorld の内部計算式ではない。
カント・車両性能・路線最高速度・加減速・運行時の速度計算は含まない。
現在の表示はこの曲線値を[線路の目標最高速度](track-design-speed.md)で上限規制する。将来の車両・運行モデルとは区別する。

各円弧自身の半径と解析的な中点を使う。経路全体の最小半径をすべての区間に
流用しない。直線には目標最高速度を表示し、不正な半径には速度を表示しない。敷設不可の診断表示は
建設可能を意味せず、既存の 25 m 最小半径や折り返し判定を緩和しない。
OSM 由来の折れ線から円弧半径を推定する処理も対象外。

従来の係数 1.0 から 1.5 に緩和（速度は丸め前で約 22% 増）。敷設中・ホバー・アンカードラッグの各区間表示は同じ計算を共有する。目標最高速度の上限は維持するため、例えば半径 1000 m・目標 120 km/h の表示は 139 ではなく 120 km/h。保存形式や線形、建設可否は変更しない。
