# 曲線制限速度の暫定表示

手描き円弧の情報ラベルは、Rosenfu の初期ゲームバランス用モデルとして
`floor(3.6 * sqrt(半径 m * 1.0 m/s²))` km/h を表示する。
横加速度の仮定は 1.0 m/s²。半径 25 / 300 / 1000 / 2000 / 8000 m はそれぞれ
18 / 62 / 113 / 160 / 321 km/h となる。

これは実際の列車速度、鉄道の安全基準、TrainsWorld の内部計算式ではない。
カント・車両性能・路線最高速度・加減速・運行時の速度計算は含まない。
線路種別による未実装の速度上限も追加しない。将来の運行モデルとは区別する。

各円弧自身の半径と解析的な中点を使う。経路全体の最小半径をすべての区間に
流用しない。直線や不正な半径には速度を表示しない。敷設不可の診断表示は
建設可能を意味せず、既存の 25 m 最小半径や折り返し判定を緩和しない。
OSM 由来の折れ線から円弧半径を推定する処理も対象外。
