# オフライン動作の現状監査

確認日: 2026-11-13 (JST)。対象はクラウド移行後の試作。
これは完全オフライン実機試験の合格証ではない。

## 現在の構造

- リリース版は `frontendDist` のローカル資産を Tauri に内蔵する。開発用 Vite サーバーや CDN が起動の必須条件ではない。
- 起動時の `engine_info` / `world_snapshot` はローカル IPC。認証・オンラインライセンス確認・外部APIの待機はこのフローにはない。
- 編集と `save_world` / `load_world` もローカル IPC。Rust storage はローカルファイルを読み書きする。
- 外部データ取得は OSM / 地理院の背景画像。失敗してもワールドの操作可否には使わない。
- サンプル背景はローカル SVG。実地理の代用品ではなく、ネットなしで設備編集を続けるための模式図。
- 日本語表示はシステムフォントを使用。現行 CSS に外部フォント・外部スタイルの取得はない。

## 自動試験で確認したこと

`src/Offline.test.tsx` の 3 件:

1. `navigator.onLine = false`、背景タイル全件エラーでもローカルワールド起動と保存・読込の操作が可能。
2. 手動でサンプルへ切り替えると外部画像ノードがなくなり、パン・ズーム後もサンプルを維持。
3. 背景取得失敗中でも、会社名変更→保存→読込が成立し状態が保持される。

実際のタイルは取得しない。jsdom は SVG 画像をロードしないため、エラーイベントを明示的に発火させる。
Tauri IPC・保存先はモックなので、この試験が示すのは UI の独立性のみ。
OS の通信遮断、HTTP キャッシュ、ネイティブ起動、実ファイル保存・再起動はこの試験では未検証。
標準 OSM タイルの一括取得・自動パン・オフライン保存は実施していない。

## 残る制約

- 起動時は OSM が既定で、背景選択はセッション限定。ネットなしでも起動できる構造だが、毎回画像取得を試みる。明示的な「外部通信なし」設定はまだない。
- 背景失敗後にサンプルへ自動で切り替えない。ユーザーが選択する。長時間失敗応答がない場合のタイムアウト通知は未実装。
- 地図タイルの通常キャッシュはオフライン保証ではない。
- 実地図の地域パック・ローカル地名/実在駅検索・実在線路/道路の追従は未実装。
- ブラウザ版は画面プレビューであり、ローカル保存可能なゲーム版ではない。
- GUI およびネットワークを遮断した Windows リリース版での実地試験は残っている。

## 次の安全な改善候補

1. 背景プロバイダーと「外部通信なし」の選択をローカル設定として保持する。`navigator.onLine` だけで通信可否を断定しない。
2. 失敗・応答待ちの画面にオフライン模式図への明確な導線を維持する。
3. [オフライン地図調査](offline-map-research.md)に従い、再配布可能な地域パックと、実在駅・線路の参照データを別途導入する。
4. Windows 実機でリリース版を起動し、通信遮断・新規編集・保存・アプリ再起動・読込・地図操作を検証する。試験は既存セーブを上書きしない専用データで行う。

この監査は新しい地図保存方式を決定しない。実在駅の表示も、ゲーム内の駅を自動建設する機能とは分離する。
