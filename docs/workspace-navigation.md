# プレイ画面のナビゲーション（暫定）

2026-11-13。大タブは「建設・路線・駅・系統・財務・都市・セーブデータ・設定」の順。
建設内に線路と駅設置をまとめ、駅管理は別タブに分離する。財務・都市は未実装表示のみ。
タブ切替で建設や編集の下書きを消さない。初期設定後の会社名変更は歯車設定へ移す。

新しいデスクトップセッションは会社名設定から開始。既存保存データを読み込んだ場合はその名前を使う。
セッション内の初期設定要否はRust側で管理し、会社名や空ワールドから推測しない。設定失敗・読込失敗時は初期設定を保持する。
タイトル画面と保存スロット一覧は未実装。現在は起動ごとに新規セッションとなり、以前のデータは手動読込する。

左パネル境界をドラッグして260〜400pxの範囲で調整する。キーボードの左右キーとHome/Endにも対応。
幅は既存の端末内表示設定に保存し、ワールド保存とは分離する。

自動テストはタブの順序・キーボード操作・初期会社設定/失敗/再試行・読込・幅変更を検証。
Windows/WebViewでの実表示、リサイズ操作、初期ダイアログのネイティブ動作は別途確認が必要。
