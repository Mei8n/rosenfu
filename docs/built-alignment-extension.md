# 建設済み線路の端部延伸

同じ Alignment ID の始点または終点へ線形を追加する。入力点列は旧端点から外側への順序で、最初の点は旧端点と完全一致すること。始点側は追加列を反転して前置する。全既存点、駅座標、路線参照は維持し、駅の正規化位置だけ距離基準で更新する。

候補全体の検証・保存可能性確認が成功した場合だけ公開する。失敗は ID 消費や部分編集を残さない。

現段階では出典付き線路、保存済み service path が参照する線路の延伸は既存の保護規則に従い拒否する。制約を迂回したり出典を消したりしない。これらの対応には区間単位の出典管理と系統経路の編集保証の別設計が必要。

これは中間分岐、立体交差、別 Alignment 同士の接続ではない。敷設モードで建設済み端点の8 CSS px以内をクリックすると、その端点から延伸計画を開始する。既存線形は着工まで変更せず、他の独立経路と同じ計画に保持できる。1計画に複数経路を保持したまま、全体候補上で延伸を含む操作を実行し一括公開する必要がある。延伸部分に駅を計画する場合は、その区間比率を延伸後の全長比率へバックエンドで変換する。
