# 線路の自動直線・曲線と設計最高速度

- 手動の「直線／曲線」切替は廃止。最初の2点は直線、その後は直前区間の接線を引き継ぐ。
- 接線の前方から画面上8 CSS px以内、かつ方向差6度以内の新しい点は接線に投影する。離すと円弧となり、1経路に直線と曲線を混在できる。
- 過去の点は動かさず、プレビューと確定クリックに同じ計算を使用。最後の点への8pxスナップとクリック終了が優先される。
- 既存線路の端からの延伸にも適用。実在線路・道路の参照形状は加工せず、従来の参照追従を維持。

## 速度

敷設設定の「設計最高速度」は線路の上限。車両の設計速度や実際の加減速・運行速度とは別。

初期値は通常120、高速300、トラム50 km/h。入力範囲は1〜600 km/h。これらは**暫定のゲーム設定**であり、実在の規格や安全な設計限界を表すものではない。

直線の表示は設計最高速度、曲線は `min(設計最高速度, floor(3.6 × sqrt(半径m)))`。曲線計算も暫定のゲームモデル。速度連動の建設費・維持費、列車シミュレーションへの反映はこの変更には含まない。

速度は経路ごとに保持する。線路種別変更でその種別の初期値となり、延伸は元線路の速度・種別を引き継ぎ、別の値への変更は許可しない。

## 保存互換

保存schemaは9。従来schema1〜8は読込可能。`design_speed_kmh` がない線路は種別の初期値として解釈する。schema9は旧アプリでは読み込めないため、旧版へ戻す場合は旧セーブのコピーを使う。
