# 水域不明時の独立した十分条件試作

この試作はアプリに接続していない。道路復旧branch、App、session、core、coverage、既存プレビューを変更しない。追加パネルはない。全国地上敷設の完成や着工許可を表すAPIではない。

## 入力と証明の境界

`worst_case.rs` は変更後の接続成分全体を対象とする。既存edge・環状・分岐を含む全spanを一度ずつ渡すことが呼出側の前提。edge-simple経路に対し、成分内の制限対象長の総和は任意の連続水域横断長の上限になる。欠落したedgeをこの関数が検出することはできない。

高さと正規化パラメータ微分は**正確な整数μm**、距離はエンジンと同じ距離尺度における**整数mmの上限**を入力する。既存f64 profileの値を単純に丸めて渡してはいけない。エンジンとのadapterは未実装。整数入力は浮動小数誤差で閾値を越える誤許可を避けるための試作用契約であり、既存保存形式の変更提案ではない。

Hermite cubicを3倍したBezier制御点へ変換し、凸包全体が既存coreの地上許容帯±1μmより上または下にある場合だけ高さ0との非接触を証明する。全制御点が-12m以下のspanのみ距離制限の免除とし、残りの長さ上限をchecked sumする。30,000,000mmは可、1mm超過は証明不成立。深さ-12mへの一点接触で連続距離を切らない。水域を全域に仮定するため、幅不明や欠落を陸地とは扱わない。

制御点の凸包は十分条件である。実際には安全な曲線でも証明できない場合がある。地上・高さ0への接触も証明できない。proof成功でも道路、線形、接続、保存整合その他の制約は別途必要。`water_ready`の変更や空間coverageの認定には使わない。

## 検証

依存追加なし。`rustc --edition=2021 -D warnings --test scripts/water-proof/worst_case.rs -o water-proof-tests.exe` と生成binaryの実行。

15 tests: 30km境界、0端点、内部0横断、接線接触、-2/-3、深い端点間の浅い内部、一点だけ-12m、既存edge/分岐/環状の合計、空入力/0長/整数overflow、±1μm境界、安全な非平坦曲線、全i64極値の組合せ、免除区間を挟む上限。4edgeの全順列と水域/免除の全割当6,144通りでも上限を検証する。これは既存アプリのHermite adapterや実グラフ抽出の回帰試験ではない。

## 原典調査（2026-11-15）

国土地理院[基盤地図情報ヘルプ](https://service.gsi.go.jp/kiban/app/help/)では全国整備、都市計画区域1:2,500相当／区域外1:25,000相当。実データDLは登録・ログインが必要。全国にファイルがあることは全水域を面として列挙する保証と別である。

[ダウンロードファイル仕様5.3](https://service.gsi.go.jp/kiban/contents/screen/basismap/documents/FGD_DLFileSpecV5.3.pdf)本文p31–32は平水時の境界を扱い、一定の公共・流域下水道を対象外とし、一条河川の種別も持つ。面なしを陸地とする根拠には不足する。原典の全水域網羅性・細流の取得/省略基準・幅の扱い・時点整合を確認するまで建設coverageは昇格しない。ログイン付き原典は取得していない。

データ利用にはコードライセンスとは別に国土地理院の利用規約が適用される。公式ヘルプは基本測量成果の複製・使用申請が必要となる場合を明示する。実配布方法に応じた条件確認は未完了であり、無条件の再配布許可と解釈しない。
